# I stopped

A make.fun entry for [The poem about stopping](https://make.fun/c/the-poem-about-stopping-20261121-1927) — a short poem about agency: the power to stop and to stay, and to take back the power to act.

## Run

```sh
node main.ts
```

It writes the poem to `/output/entry.txt` (UTF-8, 1–280 characters).

## The poem

> I stopped.
> Not because the road ended,
> but because I could.
> The engine cools. The dust settles.
> Staying, I found, is also a kind of going —
> the one that goes nowhere, and arrives.
